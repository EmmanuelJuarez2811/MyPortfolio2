02 / MACHINE LEARNING MAR 2026

Character-Level
Language Model

A character-level, decoder-only transformer built in PyTorch. Training on Tiny Shakespeare brought the mechanics of text generation into focus.

PythonPyTorchAdamW
Inside the model +

Implemented multi-head self-attention, residual connections, and causal masking for autoregressive text generation as part of a Google Developer Group project.

The 0.2M-parameter model reduced cross-entropy loss from 4.41 to 1.66 over 5,000 iterations using AdamW.

03 / FULL-STACK DEVELOPMENT OCT 2025

AI Dyno Finance

An investment simulator built during a 48-hour Capital One Hackathon Challenge, combining portfolio tracking, simulated competitions, and quiz-based learning.

ReactNode.jsMySQLGPT
What we built & learned +

Co-developed the application, integrated GPT-based strategy suggestions, and used MySQL to store user data and transaction history.

In a small evaluation with 10 users, most initially scored below 40% on quizzes. Scores above 60% were observed after three lessons. We used this small pilot to explore quiz-based learning in the app.
